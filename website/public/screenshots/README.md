# Screenshots

Place product screenshots here for use on the marketing site. Import via
`<Screenshot src="/screenshots/<file>.png" alt="…" width={…} height={…} />`.

Guidelines:
- PNG or WebP, max 1600px wide.
- Provide accurate `alt` text describing what the user sees.
- Do not stage fake user data or fabricated testimonial UI.
- Prefer `priority` only on the first above-the-fold image.
